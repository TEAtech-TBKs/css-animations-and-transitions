CSS Animations and Transitions

CSS animations and transitions are techniques used to add movement, visual effects and interactive behaviour to elements on a webpage. They help make websites more engaging, attractive and user-friendly.

For example, when you move your mouse over a button and its colour gradually changes, you are seeing a CSS transition. When a loading icon continuously rotates while a webpage is loading, you are seeing a CSS animation.

1. What Is CSS Transition?

A CSS transition is a technique that allows a CSS property to change gradually from one value to another over a specified period of time.

Normally, when a CSS property changes, the browser applies the new value immediately. A transition makes the change happen smoothly instead of suddenly.

Understanding with an example

Imagine you have a blue button. When a user moves their mouse over the button, you want its background colour to change to orange.

Without a transition, the colour changes immediately. With a transition, the colour gradually changes from blue to orange.

HTML

<button class="my-button">
    Hover Over Me
</button>

CSS

.my-button {
    background-color: blue;
    color: white;
    padding: 15px 25px;
    border: none;

    transition: background-color 0.5s ease;
}

.my-button:hover {
    background-color: orange;
}

Breaking down the CSS

  • background-color: blue; gives the button its original blue background.
  • :hover is a pseudo-class that applies styles when the mouse pointer is over the button.
  • background-color: orange; changes the background to orange when the button is hovered over.
  • transition: background-color 0.5s ease; tells the browser to gradually change the background colour over half a second.

Practical demonstration: Move your mouse over the button.

2. CSS Transition Properties

CSS provides four main transition properties. Each controls a different part of how an element changes.

A. transition-property

This property specifies which CSS property should have a transition. In other words, it tells the browser what should change smoothly. 

.box {
    transition-property: background-color;
}

The example above means that only changes to the background colour should be animated.

Other possible values include:

  • width - smoothly changes the width.
  • height - smoothly changes the height.
  • opacity - smoothly changes transparency.
  • transform - smoothly changes movement, rotation or size.
  • all - applies transitions to all properties that support transitions.

B. transition-duration

This property specifies how long the transition should take to complete. 

.box {
    transition-duration: 1s;
}

The value 1s means one second.

Time can be written using:

  • s - seconds.
  • ms - milliseconds. 1000 milliseconds equals 1 second.

Examples:

transition-duration: 2s;
transition-duration: 500ms;
transition-duration: 0.3s;
Remember: A longer duration makes the transition slower, while a shorter duration makes it faster.

C. transition-timing-function

This property controls the speed pattern of a transition. It determines how the transition accelerates and decelerates while moving from its starting value to its ending value.

Common timing functions include:

  1. ease: Starts slowly, speeds up in the middle and slows down towards the end. This is the default value.
  2. linear: Moves at a constant speed from beginning to end.
  3. ease-in: Starts slowly and gradually speeds up.
  4. ease-out: Starts quickly and gradually slows down.
  5. ease-in-out: Starts slowly, speeds up in the middle and slows down at the end. 
.box {
    transition-timing-function: ease-in-out;
}

D. transition-delay

This property specifies how long the browser should wait before starting a transition. 

.box {
    transition-delay: 1s;
}

This means that the transition will wait for one second before starting.

Combining the four transition properties

.box {
    transition-property: background-color;
    transition-duration: 1s;
    transition-timing-function: ease-in-out;
    transition-delay: 0.5s;
}

Writing all four properties separately is perfectly valid. However, CSS provides a shorter way of writing them called the transition shorthand property.

3. The transition Shorthand Property

The transition shorthand allows you to combine the different transition properties into one declaration.

General syntax:

transition: property duration timing-function delay;

Example:

.box {
    transition: background-color 1s ease-in-out 0.5s;
}

This is equivalent to writing:

.box {
    transition-property: background-color;
    transition-duration: 1s;
    transition-timing-function: ease-in-out;
    transition-delay: 0.5s;
}

You can also apply transitions to multiple properties. 

.card {
    transition:
        transform 0.3s ease,
        box-shadow 0.3s ease,
        background-color 0.5s ease;
}

Each property has its own transition duration and timing function.

4. Practical Transition Examples

Example 1: Changing a box's colour and size

<div class="box"></div>
.box {
    width: 100px;
    height: 100px;
    background: blue;

    transition: all 0.5s ease;
}

.box:hover {
    width: 200px;
    height: 200px;
    background: orange;
}

When the user hovers over the box, its width and height increase, while its background gradually changes to orange.

Example 2: Rotating an element

<div class="rotate-box">Rotate Me</div>
.rotate-box {
    width: 120px;
    height: 120px;
    background: purple;
    color: white;

    transition: transform 0.5s ease;
}

.rotate-box:hover {
    transform: rotate(45deg);
}

The transform: rotate(45deg) declaration rotates the element by 45 degrees when hovered over.

Example 3: Creating a hover effect on a card

<div class="card">
    <h3>Web Development</h3>
    <p>Learn how to build modern websites.</p>
</div>
.card {
    padding: 25px;
    width: 250px;
    background: white;
    border-radius: 10px;
    box-shadow: 0 3px 10px rgba(0,0,0,0.1);

    transition: transform 0.3s ease,
                box-shadow 0.3s ease;
}

.card:hover {
    transform: translateY(-10px);
    box-shadow: 0 12px 25px rgba(0,0,0,0.2);
}

The card moves upwards by 10 pixels and its shadow becomes more noticeable when hovered over. This creates a modern card hover effect commonly used on websites.

5. What Is CSS Animation?

CSS animation is a technique that allows an element to change from one style to another through a series of defined stages over time.

Unlike transitions, which generally require a change of state such as hovering or focusing, CSS animations can start automatically when the webpage loads and can repeat continuously.

For example, you can create:

  • A rotating loading icon.
  • A bouncing ball.
  • A text element that fades into view.
  • A box that moves from left to right.
  • A button that continuously pulses.

Understanding CSS animation with an example

Imagine you want a box to move from the left side of a container to the right side automatically.

You need to define the animation's stages and then tell the browser to execute those stages.

6. Understanding @keyframes

The @keyframes rule is one of the most important parts of CSS animation.

It allows you to define the different stages of an animation, including what an element should look like at the beginning, middle and end of the animation.

Basic syntax:

@keyframes animationName {
    from {
        /* Starting styles */
    }

    to {
        /* Ending styles */
    }
}

The words from and to represent the beginning and ending points of the animation.

Example: Changing a box's background colour

@keyframes changeColor {
    from {
        background-color: blue;
    }

    to {
        background-color: orange;
    }
}

We have created an animation called changeColor. It starts with a blue background and ends with an orange background.

However, defining keyframes alone does not make the animation run. We must apply the animation to an HTML element. 

.box {
    width: 100px;
    height: 100px;
    background: blue;

    animation: changeColor 3s;
}

The animation property tells the browser to execute the changeColor animation over three seconds.

7. Using Percentages in @keyframes

Instead of using only from and to, you can use percentages to define multiple stages of an animation.

The percentages represent how far the animation has progressed:

  • 0% - the beginning of the animation.
  • 25% - one-quarter of the animation.
  • 50% - halfway through the animation.
  • 75% - three-quarters of the animation.
  • 100% - the end of the animation.

Example: A box changing colours at different stages

@keyframes multiColor {
    0% {
        background: blue;
    }

    25% {
        background: red;
    }

    50% {
        background: yellow;
    }

    75% {
        background: purple;
    }

    100% {
        background: green;
    }
}

The box starts as blue, becomes red at 25%, yellow at 50%, purple at 75%, and green at the end.

To apply it: 

.box {
    width: 100px;
    height: 100px;
    animation: multiColor 5s;
}
Important: You can use as many percentage stages as necessary to create the movement or visual effect you want.

8. CSS Animation Properties

CSS provides several animation properties that control how an animation behaves.

A. animation-name

This property specifies the name of the animation you want to apply. It must match the name defined inside the @keyframes rule. 

@keyframes moveBox {
    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(200px);
    }
}

.box {
    animation-name: moveBox;
}

The animation name is moveBox. The element will use the stages defined inside @keyframes moveBox.

B. animation-duration

This property specifies how long one complete cycle of an animation should take. 

.box {
    animation-duration: 3s;
}

The animation will take three seconds to move from its beginning to its end.

C. animation-timing-function

This property controls the speed pattern of the animation. It determines how the animation accelerates or decelerates. 

.box {
    animation-timing-function: ease-in-out;
}

Common values include:

  • ease - starts slowly, speeds up, then slows down.
  • linear - maintains a constant speed.
  • ease-in - starts slowly and speeds up.
  • ease-out - starts quickly and slows down.
  • ease-in-out - starts and ends slowly.

D. animation-delay

This property determines how long the browser should wait before starting the animation. 

.box {
    animation-delay: 2s;
}

The animation will wait two seconds before it begins.

E. animation-iteration-count

This property determines how many times an animation should repeat. 

.box {
    animation-iteration-count: 3;
}

The animation will run three times.

You can also use:

animation-iteration-count: infinite;

This makes the animation repeat continuously without stopping.

F. animation-direction

This property specifies the direction in which an animation should play.

Common values:

  • normal - plays from the first keyframe to the last.
  • reverse - plays from the last keyframe to the first.
  • alternate - plays forward, then backward, repeatedly.
  • alternate-reverse - plays backward first, then forward.

Example:

.box {
    animation: moveBox 2s infinite alternate;
}

The box moves forward and then returns to its original position before repeating.

G. animation-fill-mode

This property determines what styles an element should retain before or after an animation runs.

  • none - the element does not retain the animation's styles before or after it runs. This is the default.
  • forwards - the element retains the styles from the last keyframe after the animation finishes.
  • backwards - applies the styles from the first relevant keyframe during the animation delay.
  • both - combines the effects of forwards and backwards.

Example:

.box {
    animation: fadeIn 2s forwards;
}

When the animation finishes, the element keeps the styles specified in its final keyframe.

H. animation-play-state

This property controls whether an animation is running or paused. 

.box {
    animation-play-state: running;
}

.box:hover {
    animation-play-state: paused;
}

In this example, the animation runs normally but pauses when the user hovers over the box.

9. The animation Shorthand Property

Just like transitions, CSS animations can be written using a shorthand property.

General syntax:

animation: name duration timing-function delay
           iteration-count direction fill-mode play-state;

Example:

.box {
    animation: moveBox 3s ease-in-out 1s infinite alternate forwards;
}

Breaking down the declaration:

  • moveBox - name of the animation.
  • 3s - duration of each cycle.
  • ease-in-out - speed pattern.
  • 1s - delay before starting.
  • infinite - repeats continuously.
  • alternate - moves forward and backward.
  • forwards - retains the final keyframe's styles.
Note: The animation shorthand has an optional play-state value. If you need to pause an animation, you can use the longhand property separately.

10. Practical CSS Animation Examples

Example 1: Creating a rotating loading icon

A loading spinner is commonly used to indicate that a webpage or application is processing something. 

<div class="spinner"></div>
.spinner {
    width: 60px;
    height: 60px;

    border: 6px solid #ddd;
    border-top-color: blue;
    border-radius: 50%;

    animation: spin 1s linear infinite;
}

@keyframes spin {
    to {
        transform: rotate(360deg);
    }
}

Explanation:

  • border creates the circular outline.
  • border-top-color changes the top section to blue, making the rotation visible.
  • border-radius: 50% makes the element circular.
  • rotate(360deg) rotates the circle through one complete revolution.
  • linear ensures that it rotates at a constant speed.
  • infinite makes the spinner rotate continuously.

Live demonstration: Rotating spinner

Example 2: Creating a bouncing or pulsing element

<div class="pulse-box"></div>
.pulse-box {
    width: 100px;
    height: 100px;
    background: blue;
    border-radius: 10px;

    animation: pulse 1.5s ease-in-out infinite;
}

@keyframes pulse {
    0% {
        transform: scale(1);
    }

    50% {
        transform: scale(1.2);
    }

    100% {
        transform: scale(1);
    }
}

The scale() function changes the size of an element. At 50%, the box becomes 1.2 times its original size. At 100%, it returns to its original size.

Live demonstration: Pulsing box

Example 3: Creating a fade-in effect

A fade-in effect makes an element gradually appear on the screen. 

<h2 class="fade-text">Welcome to My Website</h2>
.fade-text {
    animation: fadeIn 2s ease forwards;
}

@keyframes fadeIn {
    from {
        opacity: 0;
        transform: translateY(20px);
    }

    to {
        opacity: 1;
        transform: translateY(0);
    }
}

Explanation:

  • opacity: 0 makes the text completely transparent.
  • opacity: 1 makes it completely visible.
  • translateY(20px) starts the text 20 pixels below its final position.
  • translateY(0) moves it back to its normal position.
  • forwards ensures it retains its final visible state.

Example 4: Creating a slide-in effect

A slide-in animation makes an element enter the screen from a particular direction. 

.slide-text {
    animation: slideIn 1.5s ease forwards;
}

@keyframes slideIn {
    from {
        transform: translateX(-100px);
        opacity: 0;
    }

    to {
        transform: translateX(0);
        opacity: 1;
    }
}

The element begins 100 pixels to the left of its normal position and gradually moves into place.

11. Understanding CSS transform Functions

You will notice that many animation and transition examples use the transform property.

The transform property allows you to change the appearance and position of an element without changing the normal document flow.

Some commonly used transform functions include:

A. translate()

Moves an element horizontally and vertically. 

transform: translate(50px, 20px);

Moves the element 50 pixels to the right and 20 pixels down.

B. translateX()

Moves an element horizontally.

transform: translateX(100px);

Moves the element 100 pixels to the right.

C. translateY()

Moves an element vertically.

transform: translateY(-20px);

Moves the element 20 pixels upwards.

D. scale()

Increases or decreases the size of an element. 

transform: scale(1.5);

Makes the element 1.5 times its original size. 

transform: scale(0.5);

Makes the element half its original size.

E. rotate()

Rotates an element by a specified angle. 

transform: rotate(45deg);

Rotates the element 45 degrees clockwise.

F. skew()

Slants an element along the horizontal or vertical axis. 

transform: skew(20deg);

Slants the element along the horizontal axis.

Important: Transform functions can be combined. For example: transform: translateY(-10px) scale(1.05) rotate(5deg);

13. When Should You Use Transitions or Animations?

Use CSS transitions when:

  • A button changes colour when hovered over.
  • A card moves upwards when hovered over.
  • A navigation link changes its appearance.
  • An image zooms in when hovered over.
  • A form input changes its border colour when focused.

Use CSS animations when:

  • You want a loading icon to rotate continuously.
  • You want text to fade into view automatically.
  • You want an element to bounce repeatedly.
  • You want an object to move through several positions.
  • You want to create an automatically moving visual effect.

14. Common Mistakes to Avoid

  1. Forgetting to define @keyframes: An animation name must match an existing keyframes rule.
  2. Applying transition only inside :hover: In most hover effects, place the transition on the normal element so that both entering and leaving the hover state happen smoothly.
  3. Using invalid time values: Write values such as 1s or 500ms.
  4. Forgetting the animation duration: Without a duration, the animation duration defaults to zero.
  5. Using too many animations: Excessive movement can distract visitors and make a website difficult to use.
  6. Forgetting animation-fill-mode: If an element must retain its final animated style, consider using forwards.
  7. Conflicting transform declarations: If you declare transform twice in the same CSS rule, the later declaration replaces the earlier one. Combine the transform functions when necessary.

15. Performance and Accessibility Tips

CSS animations should improve the user experience, not make the website uncomfortable or slow.

  • Prefer animating transform and opacity where possible because they are generally more efficient.
  • Avoid unnecessarily animating properties such as width, height and position when transform can achieve the same effect.
  • Avoid animations that flash rapidly or move excessively.
  • Respect users who prefer reduced motion.

Understanding prefers-reduced-motion

Some users may experience discomfort from excessive movement on websites. CSS provides a media query that allows developers to reduce or remove animations for users who have enabled reduced motion in their device accessibility settings. 

@media (prefers-reduced-motion: reduce) {
    * {
        animation-duration: 0.01ms !important;
        animation-iteration-count: 1 !important;
        transition-duration: 0.01ms !important;
    }
}

18. Summary

CSS transitions and animations are important tools for creating interactive and visually appealing websites.

A transition allows a CSS property to change smoothly from one value to another, usually in response to an interaction such as hovering or focusing.

An animation allows an element to move through different visual stages defined using the @keyframes rule. Animations can start automatically, repeat continuously, move in different directions and run through several stages.

Understanding when and how to use both techniques will help you create more professional and engaging web interfaces.

Key takeaway: Transitions are particularly useful for smooth interactive changes, while animations are useful when you need more control over movement and multiple stages of an effect.
